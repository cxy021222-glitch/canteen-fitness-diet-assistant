# 智能体矩阵设计

> 「拾光 · 回忆录工坊」把「访谈录音 → 可付印书稿」拆成 12 个职责单一的智能体，由五个工位串联。本文档说明每个智能体的职责、推荐模型、输入输出与降级策略。

实际运行时，文本 / 图像 / 语音三类调用由用户在 `/settings` 选择的国内大模型驱动（见 [model-provider-matrix.md](model-provider-matrix.md)）；本文件描述的是各智能体的设计意图与推荐选型，作为 `/agents` 页的说明源。

---

## 工位 01 · 采集 Capture

### A01 声音清道夫
- **职责**：对原始录音做预处理——降噪、分段、切掉静音与串音、响度归一化。
- **推荐模型**：Silero VAD 5.1 切静音 + FRCRN 降噪。
- **降级**：能量阈值切片 + 谱减降噪，保证无模型时仍能产出可用分段。
- **输出**：`AudioTrack[]`，每段带起止时间、时长、状态。

### A02 方言听写员
- **职责**：把对话音频转成文字，逐句输出时间轴与置信度；方言是一等需求。
- **推荐模型**：SenseVoice-Small（多语种 / 方言零样本）+ Paraformer-large（普通话高准确率）；Whisper large-v3-turbo 兜底。
- **工作台实现**：选硅基流动代理时走 `/audio/transcriptions`，按方言注入提示词（粤语 / 四川话 / 闽南语 / 吴语 / 东北话 / 客家话等）。
- **输出**：`TranscriptLine[]`，每句含 `speaker` / `start` / `end` / `confidence` / 方言词标注。

---

## 工位 02 · 转写 Transcript

### A03 角色分辨师
- **职责**：区分采访者 / 讲述者，处理抢话与重叠说话。
- **推荐模型**：pyannote.audio 3.1 + CAM++（3D-Speaker）声纹聚类。
- **降级**：双声道分离 + 人工标注。
- **输出**：为每条 `TranscriptLine` 标记 `speaker`。

### A04 气口编辑
- **职责**：删除「嗯、那个、就是说、啊、嘛」等语气词与口头语、重复与半截句。
- **推荐模型**：Qwen3-32B + 自研气口规则库（`src/lib/fillers.ts`）。
- **降级**：纯正则规则清洗，零依赖。
- **输出**：清理后逐句文本，提供「轻 / 标准 / 深」三档，展示清理前后字数与删除条数。

---

## 工位 03 · 编排 Compose

### A05 故事勘探员
- **职责**：从转写素材中提炼故事主干——logline、主题、时间轴、人物 / 地点 / 物件、金句。
- **推荐模型**：长上下文 LLM（工作台运行时由 `/settings` 的 LLM 驱动）。
- **降级**：离线时使用事件抽取模板。
- **输出**：`StorySpine`。

### A06 结构建筑师
- **职责**：搭建章节骨架，提供五种叙事结构与五种叙事文风。
- **推荐模型**：LLM + 结构模板库。
- **叙事结构**：编年体 / 双线并行 / 主题式 / 口述实录 / 书信体（`NARRATIVE_PRESETS`）。
- **叙事文风**：克制纪实 / 温暖抒情 / 文学散文 / 幽默口语 / 史诗厚重（`TONE_PRESETS`）。
- **输出**：`OutlineItem[]` 章节骨架。

---

## 工位 04 · 撰写 Write

### A07 执笔人
- **职责**：按文风与结构扩写章节正文，流式逐字生成，可直接在纸面编辑器修改。
- **推荐模型**：长文 LLM + 中文口语润色模型。
- **工作台实现**：`generateChapter()` 调 `chatCompletionStream()`，把上一章结尾作为衔接上下文，system prompt 注入讲述者信息与文风 / 结构约束；返回内容增量写入章节 `body`。
- **写作指令**：细节 / 对白 / 景物 / 克制，可切换文风后按新文风重写。

### A08 事实校对
- **职责**：人名、年份、地点、称谓一致性核对，单独成块。
- **推荐模型**：GLM-4.6 + 规则校验器。
- **降级**：年份 / 人名 / 地名一致性规则。
- **输出**：校对意见列表。

---

## 工位 05 · 出版 Publish

### A09 封面画师
- **职责**：封面构图，提供六种画风。
- **画风**：木刻版画 / 水彩纪事 / 银盐胶片 / 水墨留白 / 复古丝网印 / 油画肖像（`IMAGE_STYLES`）。
- **推荐模型**：Seedream 4.0；工作台运行时由 `/settings` 的图像模型驱动。
- **工作台实现**：`generateCover()` 调 `generateImage()`，返回 base64 存入 `cover.imageUrl`；未配 Key 时用 `Artwork.tsx` 本地 SVG 兜底。

### A10 插图师
- **职责**：为每章生成插图，风格与封面统一。
- **推荐模型**：FLUX.1-dev + 风格 LoRA。
- **工作台实现**：`generateIllustration(chapterId)` 按章节摘要拼装 prompt，调用图像模型；缺失时可一键生成。

### A11 版面匠
- **职责**：开本、版心、页眉、目录、对开预览。
- **推荐**：Typst 0.13 + Paged.js。
- **开本**：A5 精装 / 32 开文库 / 16 开画册（`LAYOUT_PRESETS`）。
- **工作台实现**：`PublishPage` 提供 A5 对开预览、章节插图网格、印制预估。

---

## 工位 06 · 交付 Deliver

### A12 出版管家
- **职责**：打包、导出、归档。
- **推荐**：Pandoc + WeasyPrint + GitHub API。
- **工作台实现**：`buildBundle()` 生成 `manuscript.md`、自包含 `book.html`、`project.json`、`agent-run.json`；手写 ZIP（`src/lib/zip.ts`）打包；`pushToGitHub()` 经 Contents API 推送到用户仓库。

## 选型原则

1. **方言优先**：ASR 必须能处理方言，不接受只识别普通话的方案。
2. **可降级**：每个智能体都有「无模型 / 无 Key」时的离线路径，保证流水线不中断。
3. **国内合规**：文本 / 图像 / 语音调用均使用国内可访问的大模型端点，数据不出境（见 [model-provider-matrix.md](model-provider-matrix.md)）。
4. **可观测**：每一步都可查看、可修改、可回退；低置信度句子进入人工复核。
